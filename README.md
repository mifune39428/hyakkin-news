# 100均ニュース

ダイソー・セリア・キャンドゥ・3COINS などの100円ショップの話題を6時間ごとに集め、
日本語の見出しと要約を付けて並べる静的サイト。

集めるのは2つの軸。

- **🆕 新作** — 何が新しく出たか。新商品・再入荷・限定品・コラボ・新ブランドや新店舗。
- **💡 使い方** — どう使うと便利か。活用の工夫、比べてみた、買ってよかった・失敗した。

**ミニマリスト・ニュース（`../minimalist_news_site/`）を丸ごと写して作った**（2026-10-23）。
収集・要約・「ここ数日の傾向」・お気に入り・YouTubeの要約ページの仕組みは同じで、
違うのは収集元・軸・カテゴリ・LLMへの指示・見た目だけ。仕組みの細かい決めごとと落とし穴は
ミニマリストの README にまとまっているので、直す前にそちらも読むこと。
無印良品の話題はミニマリストのほうに任せ、ここでは集めない。

## 構成

```
collect.py          RSS収集 → LLMで見出し・要約・分類 → docs/articles.json
feeds.json          収集元の一覧（enabled で個別にON/OFF、hint で軸に寄せる）
llm_providers.py    Gemini → Groq → Claude → OpenAI の順に落ちるフォールバック
docs/index.html     一覧。PWA対応（iPhoneのホーム画面に追加できる）
docs/v.html         YouTubeの要約ページ（中身は ../news_yt_summary/ が Mac で作る）
docs/ui.js          ニュースサイト共通（上のメニューの出し入れ・お気に入り）
更新.command        ダブルクリックで手動更新 → push → 動画の要約まで
```

`.github/workflows/update.yml` が cron `0 */6 * * *`（日本時間 3/9/15/21時）で実行する。

## 収集元（2026-10-23 に全URLの疎通と、100均の記事の割合を確認）

| 種別 | 中身 | 軸 |
| --- | --- | --- |
| Googleニュース | ダイソー／セリア／キャンドゥ／3COINS ＋「新商品」、Standard Products、100均 | 🆕 新作に寄せる |
| Googleニュース | 100均 活用、ダイソー／セリア／キャンドゥ／3COINS ＋「便利」 | 💡 使い方に寄せる |
| note | #100均 #ダイソー #セリア #3COINS | LLMが判定 |
| YouTube | 100均の動画が多い12チャンネル（直近15本のうち100均の動画が10本以上のもの） | LLMが判定 |

調べたうえで入れなかったもの:

- **暮らし系メディア（ROOMIE・ヨムーノ・RoomClip mag）** — 100均の記事は20件に1件ほどで、
  1回40件の要約の枠を無関係な記事で食う。100均の記事はGoogleニュースで拾える。
- **東京バーゲンマニア・michill・サンキュ!・mamagirl** — RSSが取れない（404・空）。
- **PR TIMES の「ダイソー」検索** — F1のスポンサーなど商品と関係ない発表が多い（100件中8件）。
  新店舗・新ブランドはGoogleニュースに載る。なお `BLOCK_SOURCES` から PR TIMES は外してある
  （ミニマリストでは落としていた）。コラボの一次情報が来ることがあるため。

## ミニマリストから変えたところ

- 軸: `reduce`/`own` → `new`/`use`。`USE_QUOTA`（15件）で使い方寄りの収集元を先取りする
  （「新商品」の検索は1回で数十件届き、放っておくと使い方タブが埋まらない）。
- `KEEP_DAYS` 45日 → 30日（新作は1か月もすると店頭から消える）。
- 地域は国内だけ。地域の絞り込みは、地域が1つしか無いときは出さない。海外の枠（`GLOBAL_QUOTA`）は0。
- 見出しの指示: 店名を入れる・値段を残す・煽り言葉（神アイテム・買わなきゃ損）を使わない・数字は算用数字。
- 色は値札の赤（新作）と青緑（使い方）。アイコンは値札。

## 公開

GitHub Pages（`docs/` を公開）。Actions の Secrets に `GEMINI_API_KEY` `GROQ_API_KEY`
`ANTHROPIC_API_KEY` `OPENAI_API_KEY` を入れる（ミニマリストと同じ鍵）。手元は `.env`。
